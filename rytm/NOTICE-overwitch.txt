SK Rytm speaks the Overbridge USB protocol of the Elektron Analog Rytm MKII as documented by the Overwitch project
(https://github.com/dagargo/overwitch): the endpoints, interfaces and alternate settings, the block format and the
AR MKII's channel layout. No Overwitch code is included; SK Rytm's USB code is its own (usbfs, no libusb).
